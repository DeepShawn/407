# 别应门：无声来客 / v4.0

一个不依赖外部资源的单文件网页恐怖游戏。运行入口为 `index.html`。画面和音效均由代码生成，无第三方运行库、CDN、素材请求、账户系统或后端。不会请求摄像头、麦克风或系统通知权限。

## 本次版本的两个入口

主界面的「开始新游戏」始终进入新手教程第一章，即使之前玩过也不会跳过教程。已有教程记录时，另显示「继续教程」。

主菜单「新手教程」收纳 v3 的原有完整流程：十二个章节、八类来客、八十八次试探、生存规则、章节规则卡、剧情字幕、时间线、十二段额外录音与两种结局。教程仍然有生存难度，不是无敌演示。章节按原本顺序解锁，已解锁章节可以重玩。

主界面右侧「进入纯享版」可直接进入，不要求先完成教程。有纯享存档后变成「继续纯享版」，另有「重新开始纯享」。这两个入口与教程存档相互独立。

两种模式使用同一套十二章内容和生存规则，每种模式实际游戏计时合计约 60 分钟，不计暂停、阅读和重试；不是新增了二十四个不同章节。叙事时段从第1天 17:40 至第3天 06:00，章节之间跳时。

## 纯享版具体移除了什么

游戏中不显示剧情字幕、来客名字、特征解说、辨认倒计时、敌人阶段、正确动作条件、建议按钮高亮、任务列表、校时说明、场景说明、HUD 时钟、总进度条或危险读数。猫眼、记录机、立镜上原本绘制的教学说明也不会出现。T 键与时间线/规则入口在纯享过程中禁用，设置界面不会提供规则书。

动作按钮只显示动作名、快捷键和自己的当前操作状态，不会随敌人规则变成「松开屏息」「切断信号」等答案。屏息与顶门按钮底部保留自己的资源细条；不是危险预警。保留可见的房间、来客形态、门链、灯光、记录机物理指示灯、声音与操作反馈。

成功完成普通章节后，自动经过约 2.6 秒的暗场衔接下一章，不再弹出章节结算、规则卡或“进入下一章”提示。失败只显示「门开了」与重试/主界面，不给出死因分析或攻略。最终章结束显示简短终局画面。

主动暂停、失焦暂停、设置与异常恢复界面仍然保留。它们只负责控制游戏，不承担生存提示。恢复倒数仍保留数字，让玩家有时间重新按住动作。

## 强闪升级

主界面打开「强闪」，或在设置中启用「强闪效果」。设置提供两档曝光强度：

- 强化：单次曝光与底片残影，白色叠加峰值透明度 0.42。
- 剧烈：更强曝光、更重残影，白色叠加峰值透明度 0.78；新设置默认选中此档，但强闪开关默认关闭。

v3 的额外闪光峰值透明度为 0.18。这里比较的是代码中的叠加透明度，不是显示器实测亮度，也不代表体感按相同比例增加。

新效果由短黑场、一次曝光、底片人脸、固定错位切片、残像消退与单次视角冲击组成。强闪可与撞门、反窥、镜中残影、周边人影和失败画面配合。不通过循环频闪或无限增大音量来制造冲击。

额外强闪在同一页面会话内使用统一冷却：两次至少间隔 6 秒，游戏活动计时与真实经过时间都需要达到间隔。换章节、重试或切换模式不会重置该冷却。低刺激模式、系统减少动态效果都会抑制强闪；按 X 或右上角闪电按钮立即关掉当前强闪及开关。暂停会取消正在展示的额外闪光，不改变生存判定。

**强闪默认关闭，需主动启用。对闪光或强烈惊吓敏感者请保持关闭，并开启低刺激模式。未经专业光敏分析或医学安全认证；冷却限制不代表对任何人都安全，也不能保证每个人都会被吓到。**

升级时不会把 v3 的“有限闪光”许可静默升级成 v4 强闪许可，需要重新打开开关。

## 存档与更新

运行文件仍为根目录的 `index.html`，无需编译。用本文件替换旧版入口即可；不需要上传测试目录才能运行游戏。

保存键：

- `dna.campaign.v4.tutorial`：教程解锁、章节起点、档案、死亡与结局。
- `dna.campaign.v4.pure`：纯享版的独立记录。
- `dna.settings.v4`：音量、低刺激、强闪与下一章节难度。

第一次读取 v4 时，没有教程存档就尝试导入可访问的 `dna.campaign.v3`。不会删除或改写 v3 的存档键，也不会将教程进度复制到纯享版。设置优先使用 v4，再读取旧设置的音量等内容；强闪许可只接受 v4 的明确设置。

迁移需要当前页面能访问旧站点的存储。换浏览器、无痕模式、清除网站数据或改变站点来源，都可能使旧记录不可访问。本地存储不可用时，游戏仍可运行，但关闭页面不能保留记录，主菜单会注明。存档只保存到章节起点，不恢复章内某一秒。

「开始新游戏」「从第一章开始」「重新开始纯享」会把对应模式的继续位置设为第一章，但不删除已经解锁的章节、收集的档案和结局。两种模式互不覆盖。

## 失焦恢复

切换窗口、隐藏标签页或页面离开时，冻结活动状态、释放所有长按与指针捕获，暂停声音。返回不会自动恢复敌人；明确点击继续后，进行 1.8 秒准备倒数。普通游戏的准备倒数期间可调整视角与防守姿态，但不会恢复资源或推进敌人。

纯享版的章节暗场切换也能暂停和恢复，不会因为失焦跳过章节或被卡在暂停界面。详见 `TESTING.md` 的测试范围与限制。

## 开发文件

运行只需要 `index.html`。`.nojekyll` 为空文件。`tests/*.py` 是可选的开发回归脚本，依赖 Python 与 Playwright，不是游戏运行依赖。`tests/reports/*.json` 为本次实际运行报告。截图不包含动态闪烁预览。
