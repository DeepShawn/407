# 别应门：失序之夜

DO NOT ANSWER · TIMELINE EDITION · v2.0

围绕“公寓门外的来客”展开的单人网页心理恐怖游戏。保留旧版的木门、猫眼与低照度场景，将单次守夜扩展为六章连续剧情。

## 运行文件

`index.html` 是完整游戏，包含 HTML、CSS、JavaScript、程序化画面和合成音效。没有外部图片、字体、音频、第三方库、CDN、网络请求、后端或构建流程。支持静态站点托管。

将新版 `index.html` 替换旧版入口文件即可。其余 Markdown 文件仅为说明，`.nojekyll` 是空标记文件。部署由你自行完成。

可尝试直接用浏览器打开 HTML。部分浏览器会限制本地文件的声音或存储；静态 HTTP/HTTPS 托管更适合正式游玩。游戏仅在点击“留在门内”后初始化声音；不会调用摄像头、麦克风或语音服务。对白以字幕呈现，敲门、脚步、低语感噪声、金属与环境音由 Web Audio 合成。

## 六章时间线

页面上的时钟是虚构剧情时间，不是设备当前时间。04:42 至 05:00 共十八分钟剧情，被压缩成正常运行时约 11 分 30 秒的有效游玩时间；规则卡、暂停、时间线阅读和失败重试不包含在内。

| 章节 | 剧情时间 | 本章正常时长 | 新规则 |
| --- | --- | --- | --- |
| 01 第一次敲门 | 04:42–04:45 | 90 秒 | 关灯与屏息 |
| 02 另一只眼睛 | 04:45–04:48 | 105 秒 | 用挡片阻止反窥 |
| 03 门链的重量 | 04:48–04:51 | 110 秒 | 按住顶门，管理腕力 |
| 04 它没有走 | 04:51–04:54 | 120 秒 | 双重试探，利用中间的换气窗口 |
| 05 断电层 | 04:54–04:57 | 125 秒 | 停电、复电与组合防守 |
| 06 五点并不安全 | 04:57–05:00 | 140 秒 | 伪造的五点与最终组合试探 |

每章开始前显示规则卡，点击按钮后才开始计时。每次成功守住一章会解锁下一章。完整流程共有二十次需要应对的试探，另外穿插不直接判定死亡的惊吓与叙事事件。部分试探的发生时刻有小幅随机变化。

## 操作

| 按键 | 操作 |
| --- | --- |
| L | 开关灯，停电期间无法打开 |
| 空格（按住） | 屏息，松开恢复呼吸 |
| E（按住） | 观察猫眼，需要先打开挡片 |
| C | 开关猫眼挡片 |
| R（按住） | 顶住门链，从第三章起启用 |
| T | 打开／关闭时间线，打开时暂停 |
| Esc | 暂停／继续，或关闭当前对话框 |
| M | 静音／取消静音 |

手机使用屏幕按钮。后期可用左拇指按住“顶住门链”，右拇指按住“屏住呼吸”；按住后滑出按钮仍保持操作，松手或触控取消即停止。可以先完成关灯、遮眼，再同时屏息与顶门。

屏息能力约十秒，腕力约十三秒；松开可恢复，耗尽会强制松开并进入短暂恢复期。按钮上方会列出当前防守条件，满足条件后标记会改变。危险同时有文字提示，静音仍可玩。门外的对白可能说谎；顶部的危险提示与操作条件是可靠指引。

## 时间线与档案

时间线包含六章的剧情区间、已亲历事件的剧情时刻、碎片、解锁进度和结局记录。未来事件不会提前展开；日志会跨重试累积，因此不是单次游玩的录像。主界面上方的六个节点也可用于打开相应章节档案。

每章有一次纸条出现的机会。按提示打开挡片，短看猫眼约 0.7 秒可记下一个碎片。停留过久会遭到反窥。碎片不是通关必需品，未收集也可以守到最终章结束。

存在两种最终结局，另有按失败原因区分的死亡反馈。集齐六片后完成第六章，会进入另一种结局。碎片支持跨重试收集；补齐后可直接重玩第六章。已经集齐所有碎片时，第六章规则卡还会提供“本次只守门，不拼合档案”选项，用于体验另一条结局分支。具体剧情不在此剧透。

## 保存、继续与重玩

在浏览器允许本地存储时，自动保存已解锁章节、章节起点、已完成章节、碎片、日志、结局和设置。失败可直接重试当前章；刷新或下次打开时从保存章节的开头继续，不恢复到章内某一秒。

存档仅存在当前浏览器、当前站点来源下，不跨设备同步。清理网站数据、切换浏览器或域名可能导致存档不可见。浏览器拒绝存储时会显示说明，仍可完成当次游戏，但关闭页面后不会保留进度。

“从第一章开始”只重新开始守夜，不删除已解锁内容或档案。可在时间线重玩已解锁章节。v2 的新剧情存档使用 `dna.campaign.v2`；音量、静音与低刺激偏好继续使用旧版 `dna.settings.v1`。

## 惊吓与低刺激模式

含近距离人形面孔、静默后的突发音效、门缝手指、镜片反窥、门链撞击、假离场和假天亮，没有血腥画面。请保持适中音量，不要为了增强效果盲目开大耳机音量。

低刺激模式关闭突脸图像，替换为暗色遮罩，减弱突发音效并减少运动效果，但不会改变通关条件。页面失焦或切换标签页时自动暂停。打开时间线同样暂停声音和计时，关闭后可继续。

## 修改代码

所有内容在一个 HTML 内。`CHAPTERS` 配置章节标题、剧情起点、时长、规则和碎片。`createEvents()` 定义各章事件及危险。`beginThreat()`、`threatNeeds()` 和 `update()` 处理危险、输入与胜负。`Soundscape` 合成音效；`drawRoom()`、`drawPeephole()` 和 `drawScare()` 绘制场景。

各章事件时间使用真实游玩秒数。如果缩短 `duration`，务必同步修改该章最后几个事件，避免最后一轮试探在关卡结束后才触发。若改动章节数或大幅变更存档结构，也需调整解锁、时间线与存储校验逻辑。

测试范围和未验证项见 `TESTING.md`。
